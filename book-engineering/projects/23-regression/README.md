# پروژه فصل ۲ جلد دوم: رگرسیون

روی CPU، Python 3.13.16، NumPy 2.3.5 و scikit-learn 1.6.1 اجرا شد. `python regression.py` و `python -m unittest -v`. نصب پیشنهادی: `python -m pip install numpy==2.3.5 scikit-learn==1.6.1`. داده فقط مصنوعی و تولیدشده با seed=42 است. هر دو مدل رگرسیون: MAE=0.229346 و MSE=0.081311؛ هر دو مدل طبقه‌بندی accuracy=0.716667 و logloss=0.494112. حل‌گر SciPy هشدار منسوخ‌شدن داد ولی تست شکست نخورد. هیچ نتیجه‌ای برای داده واقعی ادعا نمی‌شود.
