# پروژه فصل ۳ جلد دوم: انتخاب مدل

Python 3.13.16، NumPy 2.3.5، scikit-learn 1.6.1 روی CPU؛ اجرا: `python classical_models.py` و `python -m unittest -v`. نصب: `python -m pip install numpy==2.3.5 scikit-learn==1.6.1`. داده ۴۰۰ ردیف کاملاً مصنوعی با seed=42 است.
