# پروژه فصل ۳ جلد دوم: انتخاب مدل

Python 3.13.16، NumPy 2.3.5، scikit-learn 1.6.1 روی CPU؛ اجرا: `python classical_models.py` و `python -m unittest -v`. نصب: `python -m pip install numpy==2.3.5 scikit-learn==1.6.1`. داده ۴۰۰ ردیف کاملاً مصنوعی با seed=42 است. Pipeline انتخاب ویژگی و مقیاس‌گذاری را داخل CV انجام می‌دهد. خروجی ثبت‌شده: جنگل، میانگین CV F1=0.835412، آزمون accuracy=0.92 و F1=0.9 و ماتریس [[56,4],[4,36]]. نتیجه به داده و نسخه وابسته است و برتری عمومی نیست.

## قرارداد KNN دستی
`knn_predict(rows, query, k)` برای آموزش با فهرست پایتون طراحی شده است: `rows` فهرست جفت‌های `(vector, label)`، هر بردار و `query` فهرست غیرخالی اعداد با طول یکسان، و هر برچسب یک `int` پایتون است. برچسب `numpy.int64` و آرایه NumPy به‌عنوان `rows` یا `query` جزو قرارداد نیستند؛ در صورت نیاز ورودی را آگاهانه به فهرست و برچسب را به `int` تبدیل کنید. `k` باید بین یک و تعداد ردیف‌ها باشد. داده خالی، k خارج از بازه، بُعد ناسازگار و برچسب غیر `int` با ValueError رد می‌شوند؛ اعتبارسنجی کامل مقدارهای غیرمتناهی و نوع همه مؤلفه‌ها در این نمونه پیاده نشده است. تساوی فاصله با اندیس ورودی و تساوی رأی با کوچک‌ترین برچسب شکسته می‌شود.
