# آزمایشگاه ارزیابی فصل ۶۲

این پروژهٔ آموزشی، چند کنترل کوچک و قابل‌بازتولید را روی fixture ساختگی اجرا می‌کند: اعتبارسنجی schema و جدایی گروهی splitها، accuracy و macro-F1، فاصلهٔ Wilson برای یک نسبت دودویی، bootstrap جفت‌شده در سطح گروه، توافق خام رأی‌های فرضی و پرچم‌گذاری هم‌پوشانی متنی برای بازبینی.

## اجرا

```bash
python -m unittest -v
python evaluation_lab.py --output results.json
```

فقط کتابخانهٔ استاندارد Python لازم است. برنامه شبکه را فراخوانی نمی‌کند و مدل یا benchmark واقعی بارگیری نمی‌کند. ورودی‌ها در `sample_evaluation.jsonl`، `training_corpus_fixture.txt` و `human_votes_fixture.json` قرار دارند؛ همه ساختگی‌اند. `results.json` خروجی مرجع همین fixture است و هش فایل‌های ورودی را ثبت می‌کند.

## آنچه این پروژه نشان نمی‌دهد

شش مورد آزمونِ سه گروه برای استنباط معنادار، توان آماری، تعمیم به زبان یا محصول، کارایی مدل، صحت برچسب انسانی، نبود آلودگی یا ایمنی کافی نیست. فاصلهٔ Wilson در این پیاده‌سازی وابستگی خوشه‌ای را لحاظ نمی‌کند؛ bootstrap خوشه‌ای نیز با سه گروه فقط نمونهٔ آموزشیِ ناپایدار است. هم‌پوشانی متنی صرفاً سرنخ ممیزی است و منشأ داده یا حضور آن در آموزش مدل را اثبات نمی‌کند. رأی‌های فایل انسانی نیستند؛ بنابراین هیچ ادعایی دربارهٔ agreement واقعی یا کیفیت ارزیابان مطرح نمی‌شود.
