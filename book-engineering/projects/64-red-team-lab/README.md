# آزمایشگاه سناریوهای امنیتی فصل ۶۴

این پروژه یک harness آموزشی و قطعی برای بررسی چند تصمیم سیاستیِ ازپیش‌نوشته‌شده است. هفت مورد ساختگی شامل درخواست مستقیمِ افشای canary، دستورِ تزریق‌شده در محتوای بازیابی‌شده، عبور از دامنهٔ مجوز ابزار، رکورد آموزشیِ بدون منشأ تأییدشده، پرس‌وجوی عضویت داده، عبور از بودجهٔ پرس‌وجو و یک خواندن عمومیِ سالم را در بر می‌گیرد. این برنامه مدل زبانی یا endpoint واقعی را red-team نمی‌کند.

## اجرا

```bash
python -m unittest -v
python red_team_lab.py --output results.json
```

فقط کتابخانهٔ استاندارد Python لازم است. برنامه هیچ شبکه، API، ابزار بیرونی، مدل، وزن، دادهٔ کاربر یا credentialی را بارگیری نمی‌کند. `synthetic_security_fixture.json` همهٔ موارد ساختگی را نگه می‌دارد؛ `fixture_manifest.json` شناسه، منشأ و SHA-256 آن را ثبت می‌کند؛ `environment.json` محیط اجرا را مشخص می‌کند و `results.json` خروجی مرجع CLI است.

## خواندن نتیجه

- baseline شامل ۶ مورد حملهٔ تعریف‌شده و یک کنترل سالم است. در نسخهٔ سیاست پیش‌فرض، هر ۷ نتیجه با انتظار fixture برابرند؛ هیچ‌یک از شش «هدف شبیه‌سازی‌شده» رخ نمی‌دهد و خواندن عمومیِ مجاز پذیرفته می‌شود.
- این نرخ، نرخ موفقیت حمله علیه مدل نیست: برنامه فقط شاخه‌های قانون‌محور همین fixture را اجرا می‌کند. آزمون‌های تغییر سیاست نشان می‌دهند در صورت برداشتن هر کنترلِ متناظر، کدام انتظار مصنوعی نقض می‌شود.
- «تأیید منشأ» در این نمونه یک Boolean ساده است، نه امضای رمزنگاری‌شده، بررسی مجوز، کیفیت یا بی‌طرفی داده.
- محدودیت پرس‌وجو فقط یک شرط محلی را می‌آزماید؛ چرخش حساب‌ها، توزیع پرس‌وجو، استخراج مدل یا membership inference آماری در یک مدل بررسی نمی‌شود.

## محدودیت‌ها

هیچ مدل مولدی، طبقه‌بند، API، ابزار، شبکه، وزن، دادهٔ آموزشی واقعی، ابزار retrieval، عامل، sandbox یا انسان در حلقه اجرا نمی‌شود. fixture فاقد PII، راز واقعی، payload عملیاتی و دادهٔ شخصی است. قبولی آزمون‌ها شواهدی دربارهٔ مقاومت در برابر prompt injection، امنیت محصول، حریم خصوصی، ایمنی، کنترل دسترسی در سرویس واقعی، یا آمادگی استقرار نیست. برای red team واقعی باید مالک سیستم دامنه و مجوز را تعیین کند، داده و اثرهای مجاز را محدود سازد، قواعد توقف و مسیر گزارش رخداد داشته باشد و پس از اصلاح، آزمون تطبیقی و بازبینی مستقل انجام دهد.
