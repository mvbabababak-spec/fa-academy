# پروژه فصل ۱ جلد دوم — شیوه‌های یادگیری

Python 3.13.16 و scikit-learn 1.6.1 روی CPU آزموده شد. داده مصنوعی است. از همین پوشه: `python learning_paradigms.py` و `python -m unittest -v`. خروجی ثبت‌شده: اعتبارسنجی baseline=0.500، آستانه دستی=0.750، درخت=1.000، انتخاب درخت و آزمون=1.000. این نتایج نشانه کیفیت مدل واقعی نیستند. در صورت نیاز نصب: `python -m pip install scikit-learn==1.6.1` در محیط مجازی. خروجی نسخه‌های دیگر ممکن است تفاوت کند. محدودیت: شناسه تکراری بررسی می‌شود ولی تمام راه‌های نشت یا کیفیت داده بررسی نمی‌شود.
