# آزمایشگاه مستندسازی و حکمرانی فصل ۶۵

این پروژه یک validator کوچک برای ساختار یک بستهٔ ساختگی حکمرانی هوش مصنوعی است. نمونهٔ CampusGuide، سامانه‌ای خیالی برای توضیح قواعد آموزشی، چهار ریسک، یک model card، یک data card، چند شناسهٔ شاهد و یک تصمیم `hold` دارد. همهٔ نام‌ها، نقش‌ها و داده‌ها آموزشی‌اند؛ هیچ دانشگاه، دانشجو، مدل یا مدرک واقعی در آن دخیل نیست.

## اجرا

از همین پوشه اجرا کنید:

```bash
python -m unittest discover -v
python governance_check.py --output results.json
```

فقط کتابخانهٔ استاندارد Python لازم است. ورودی پیش‌فرض `governance_pack.json` است. برنامه schema و پیوندهای داخلی را بررسی و JSON قطعی می‌سازد؛ اگر ورودی نامعتبر باشد، خروجی خطاها را می‌نویسد و با کد غیرصفر پایان می‌یابد.

## تفسیر خروجی

`structurally_valid: true` فقط یعنی فیلدهای نمونه و ارجاع‌های داخلی با قرارداد این validator سازگارند. خروجی هرگز مجوز استقرار نمی‌دهد؛ `release_authorized` همیشه `false` است و تصمیم نمونه `hold` باقی می‌ماند. شناسه‌های `EV-*` فقط placeholderهای ساختگی‌اند، نه گزارش آزمون یا تأیید انسانی.

## مرز ادعا

این پروژه قانون‌سنج، گواهی انطباق، ارزیابی اثر واقعی، ارزیابی model card، بررسی مجوز داده، تست حریم خصوصی، آزمون مدل یا رأی هیئت حاکمیت نیست. وجود فیلد «منشأ»، hash یا برچسب کیفی صحت، مجوز، کیفیت، بی‌طرفی یا نبود PII را ثابت نمی‌کند. هیچ مدل، شبکه، API، دادهٔ واقعی یا تصمیم انتشار اجرا نمی‌شود. برای استفادهٔ واقعی، مالک پاسخ‌گو باید حوزهٔ قضایی، نقش‌ها، آثار بر افراد، کیفیت شواهد و معیارهای پذیرش را مستقل بررسی کند؛ نظر حقوقی را از مشاور صلاحیت‌دار بگیرد و تأیید انسانی ثبت کند.
