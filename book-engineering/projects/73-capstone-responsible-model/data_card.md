# داده‌کارتِ fixture نهایی جلد پنجم

## خلاصه

این fixture مجموعه‌ای کوچک و کاملاً ساختگی برای تمرین زنجیرهٔ «داده تا تصمیم انتشار» است. ۸ ردیف آموزش، ۴ ردیف اعتبارسنجی و ۴ ردیف آزمون دارد؛ هر ردیف دو عدد آموزشی (`x1` و `x2`) و یک برچسب دودویی (`toy_label`) دارد. برچسب با قاعدهٔ آشکار `x1 + x2 > 0` ساخته شده است.

## منشأ و گردآوری

همهٔ مقادیر را برای همین تمرین به‌صورت دستی و قطعی نوشته‌ایم؛ آن‌ها از مشاهدهٔ اشخاص، دستگاه، وب‌سایت، پژوهش، API یا مدل بیرونی نیامده‌اند. نمونه‌ها و شناسه‌ها رویداد یا فرد واقعی را نمایش نمی‌دهند. fixture هیچ دادهٔ شخصی، متن کاربر، شناسهٔ واقعی، فایل محرمانه یا خروجی مدل بیرونی ندارد.

## ترکیب و split

تقسیم train/validation/test از ابتدا در `synthetic_fixture.json` ثبت شده است؛ شناسه‌ها میان سه split یکتا هستند. کد فقط split آموزش را برای به‌روزرسانی وزن‌ها می‌خواند. اعتبارسنجی و آزمون پس از آموزش برای محاسبهٔ سنجه‌های توصیفی استفاده می‌شوند؛ هیچ بازنمونه‌گیری، آزمون فرضیه یا ادعای استنباطی اجرا نمی‌شود.

## تبدیل و برچسب

هیچ نرمال‌سازیِ آموخته‌شده، فیلتر، حذف ردیف یا استخراج ویژگی وجود ندارد. قاعدهٔ برچسب بخشی از fixture است و خودِ سادگی آن مهم‌ترین محدودیت این آزمایش است: مدل می‌تواند مرزی را یاد بگیرد که پاسخ از پیش با همان رابطه ساخته شده است.

## استفادهٔ مجاز و بیرون از دامنه

استفادهٔ مناسب، اجرای آموزشی کد و بررسی مسیرهای اعتبارسنجی، آموزش، ارزیابی و ثبت منشأ است. این fixture نمایندهٔ هیچ جمعیت، زبان، دامنه، رفتار، رخداد یا مسئلهٔ واقعی نیست؛ برای تصمیم‌گیری دربارهٔ اشخاص، آموزش محصول یا برآورد عملکرد در محیط واقعی مناسب نیست.

## نگه‌داری، مجوز و محدودیت

`fixture_manifest.json` هش فایل را ثبت می‌کند تا تغییر bytes آشکار شود؛ هش، منشأ یا کیفیت علمی را اثبات نمی‌کند. برای همین fixture هیچ منبع دادهٔ بیرونی یا شرط دسترسیِ بیرونی وجود ندارد. مجوز بازاستفادهٔ جداگانه تعیین نشده است؛ پیش از بازتوزیع یا استفادهٔ بیرون از این مثال، حقوق و سیاست مخزن را بررسی کنید. «ساختگی» به‌تنهایی برای هر داده‌ای تضمین بی‌خطری نیست؛ این مورد مشخصاً از مقادیر دستی و غیرشخصی ساخته شده است.
