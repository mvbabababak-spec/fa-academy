# پروژهٔ فصل ۵۵: دفتر طراحی آزمایشگاه

این برنامه چهار طرح کاملاً ساختگی را از روی ظرفیت‌هایی که در JSON وارد شده‌اند با هم می‌سنجد: آزمایشگاه شخصی، workstation مستقل حرفه‌ای، یک طرح کلاستر سازمانی و یک طرح عمداً ناکافی. هیچ قطعه یا SKU واقعی، قیمت، اندازه‌گیری، اتصال به حسگر یا benchmark در پروژه نیست. برچسب `paper_feasible` یعنی فقط قیود عددیِ همان fixture پاس شده‌اند؛ به معنی سازگاری واقعی، ایمنی برق، کفایت خنک‌کاری یا آمادگی استقرار نیست.

## اجرا

```bash
python lab_design_planner.py
python lab_design_planner.py --output /tmp/lab-screen.json
python -m unittest -v
```

`results.json` تصویر ممیزیِ fixture فعلی است: خروجی deterministic به‌علاوهٔ hash و خلاصهٔ اجرای آزمون. اجرای CLI در مسیر دلخواه بخش `profiles` را بازتولید می‌کند؛ برای مقایسه، شناسه و SHA-256 fixture را هم کنترل کنید.

## چه چیزهایی محاسبه می‌شوند؟

- نیاز VRAM را **برای هر شتاب‌دهنده** با سهم قابل‌استفادهٔ فرضی مقایسه می‌کند؛ حافظهٔ چند کارت را با هم جمع نمی‌زند.
- حداقل RAM میزبان، تعداد node/شتاب‌دهنده و تعداد جایگاه اعلام‌شده را کنترل می‌کند.
- فضای ذخیره‌سازی لازم را از dataset × تعداد working copy، نسخه‌های checkpoint، scratch و backup جمع می‌زند.
- جمع مقادیر input-power اعلام‌شده برای nodeها، تجهیزات شبکه و بارهای دیگر را با ظرفیت تخصیص‌یافتهٔ سایت مقایسه می‌کند.
- بار گرمایی را با تبدیل `W → Btu/h` و ضریب سناریویی fixture به یک screen ساده تبدیل می‌کند.
- ظرفیت اعلامیِ PSU و نرخ اسمی شبکه را با ورودی طرح مقایسه و بسته‌های نرم‌افزاریِ اعلام‌شده را تطبیق می‌دهد.

## مرز ادعا

اعداد حافظه، توان، ظرفیت سایت، سرمایش، شبکه و سازگاری در fixture ساخته شده‌اند. ابزار datasheet، توپولوژی PCIe/NUMA، کابل، connector، thermal curve، ولتاژ/جریان، مدار برق، مقررات محلی یا مستند پشتیبانی نرم‌افزار را بررسی نمی‌کند. `cooling_design_factor` و `usable_vram_fraction` فقط فرض‌های آموزشی‌اند، نه ضریب طراحی عمومی. ظرفیت برق سایت باید از facility/برق‌کار واجد صلاحیت گرفته شود؛ این ابزار مدار یا سیم‌کشی را سایز نمی‌کند.

برای شبکه، نرخ اعلامی فقط line-rate اسمی است، نه throughput کاربرد. برای گرما، تمام input power برنامه‌ریزی‌شده را به گرمای معادل تبدیل می‌کنیم؛ بار ساختمان، تابش، رطوبت، شرایط ورودی هر دستگاه، اتلاف سامانهٔ HVAC و redundancy در آن مدل نشده‌اند. ساخت، نصب، راه‌اندازی، دادهٔ حساس، ایمنی، benchmark و هزینه نیز ارزیابی نشده‌اند.
