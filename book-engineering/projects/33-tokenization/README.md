# پروژه فصل ۱ جلد سوم — توکن‌ساز Byte-Level BPE آموزشی

این پروژه یک توکن‌ساز کوچک و قطعی از صفر می‌سازد: پیش‌توکن‌ساز ساده، الفبای ۲۵۶ بایت UTF-8، ادغام‌های پرتکرار BPE، شناسه‌های ویژه، بازسازی متن، ذخیره و بارگذاری جدول ادغام‌ها. داده آموزشی و ارزیابی ساختگی و کوتاه‌اند؛ هیچ مدل زبانی آموزش داده نمی‌شود و دقت معنایی یا کیفیت فارسی از شمار توکن‌ها نتیجه نمی‌شود.

## اجرا و محیط

- Python 3.13.16؛ منطق BPE فقط به کتابخانه استاندارد Python نیاز دارد.
- بخش آزمون lookup از PyTorch 2.6.0 روی CPU استفاده می‌کند؛ GPU لازم نیست.
- نصب PyTorch CPU در محیط مجازی: `python -m pip install torch==2.6.0 --index-url https://download.pytorch.org/whl/cpu`
- از این پوشه اجرا کنید: `python tokenizer_bpe.py` و `python -m unittest discover -v`.
- خروجی مرجعِ کامل اجرا در گزارش `book-engineering/chapters/33-audit-report-fa.md` ثبت می‌شود. به‌دلیل نسخه یا محیط متفاوت، هر اختلاف باید ثبت شود، نه پنهان.

## قرارداد و محدودیت

- شناسه‌های ویژه ثابت‌اند: PAD=0، BOS=1، EOS=2، UNK=3؛ بایت‌ها از 4 تا 259 و ادغام‌ها از 260 آغاز می‌شوند.
- در این نمونه، شناسه 260 برای ادغام نخست `ab` به‌کار می‌رود. شکستن ورودی با regex ساده و نرمال‌سازی نکردن عمدی است تا اثر تنظیمات دیده شود.
- هر متن UTF-8 معتبر، حتی نویسه‌ای که در داده آموزش نبوده، با بایت‌ها بازنمایی و بدون UNK بازسازی می‌شود. این تضمین پوشش بایتی و بازسازی است، نه دانستن معنا.
- این کد پیاده‌سازی تولیدی tiktoken، GPT-2، SentencePiece یا قالب گفت‌وگوی هیچ مدل خاصی نیست. پیش‌توکن‌ساز، الگوریتم، واژگان و شناسه‌ها با مدل عوض می‌شوند.
- ذخیره فایل فقط قرارداد توکن‌ساز و ادغام‌ها را ثبت می‌کند؛ وزن‌های یک LLM یا embedding آموزش‌دیده در آن وجود ندارد.
