# پروژهٔ فصل ۳۶: موقعیت و بلوک Transformer

این پروژه دو راه متفاوت برای افزودن اطلاعات ترتیب را از هم جدا می‌کند: بردار sinusoidal به بازنمایی ورودی جمع می‌شود؛ RoPE جفت مختصات `Q/K` را با زاویهٔ وابسته به موقعیت می‌چرخاند و `V` را نمی‌چرخاند. سپس یک بلوک آموزشی با attention کامل، دو مسیر residual، `LayerNorm` در حالت Pre-LN یا Post-LN و FFN موقعیت‌مند اجرا می‌شود.

## نیازمندی و اجرا

- Python 3.11 یا جدیدتر
- PyTorch 2.6.x؛ CPU کافی است و CUDA لازم نیست.

از همین پوشه:

```bash
python transformer_block.py
python -m unittest -v
```

خروجی نمونه باید `input_shape=(2, 6, 16)`، `output_shape=(2, 6, 16)`، `sinusoidal_shape=(6, 16)` و `output_finite=True` گزارش کند. ده آزمون، فرمول و بُعد موقعیت، زوج‌بودن head dimension در RoPE، حفظ norm بردار، وابستگی امتیاز به فاصله نسبی، شکل خروجی بلوک، گرادیان residual و ورودی نامعتبر را می‌سنجند.

این مرجع آموزشی dropout، padding/causal mask، توجه cross، آموزش چندلایه، positional interpolation و ارزیابی تعمیم به طول‌های خارج از آموزش را پوشش نمی‌دهد. RoPE و سینوسی گزینه‌های این نمونه‌اند؛ انتخاب موقعیت در هر مدل به معماری و هدف وابسته است. اجرا روی CPU سرعت یا کیفیت یک LLM کامل را نشان نمی‌دهد.
