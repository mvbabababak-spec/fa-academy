# پروژهٔ فصل ۷۰: خواندن مقاله و بازتولید نتیجه

این پروژه فقط یک بستهٔ آموزشی ساختگی را می‌خواند. عنوان مقاله، داده، عددها، ادعاها، گروه‌ها و artifactها همگی خیالی‌اند و به پژوهش یا مدل واقعی اشاره ندارند. اجرای پروژه، مقالهٔ بیرونی را ارزیابی نمی‌کند و بازتولید پژوهشی واقعی نیست.

## نیازمندی و اجرای آفلاین

- CPython 3.13؛ فقط کتابخانهٔ استاندارد پایتون، بدون وابستگی نصب‌شدنی.
- شبکه، GPU، credential، دادهٔ شخصی، checkpoint و inference واقعی استفاده نمی‌شود.
- از این پوشه اجرا کنید:

```sh
python3.13 -m unittest -v test_paper_reproduction.py
python3.13 paper_reproduction.py --packet synthetic_paper_packet.json --output /tmp/paper-results.json
cmp results.json /tmp/paper-results.json
```

فرمان دوم fixture را می‌خواند، شناسهٔ فایل را با SHA-256 در خروجی ثبت می‌کند و نتیجهٔ JSON می‌نویسد. `cmp` باید بدون پیام و با exit code صفر تمام شود؛ این تطبیق فقط پایداری همین پروژه و همین fixture را می‌سنجد.

## تفسیر نتیجه

- `C1` به داده و پروتکل ثابت همین fixture محدود است. `reproduced_within_tolerance` یعنی MAEهای محاسبه‌شده با آستانه‌های اعلام‌شده در خود بسته سازگارند؛ این نتیجه دربارهٔ الگوریتم یا مطالعهٔ واقعی چیزی ثابت نمی‌کند.
- `C2` به checkpoint و tokenizer نیاز دارد که عمداً در بسته نیستند؛ وضعیت `blocked` است، نه رد ادعا.
- `C3` به دادهٔ یک دامنهٔ مستقل نیاز دارد که موجود نیست؛ وضعیت `not_assessed` است، نه شکست بازتولید.
- نتیجهٔ کلی `partial_or_unassessed` است. پروژه عمداً از تبدیل کمبود شواهد به شاهد نادرستی خودداری می‌کند.

فایل `fixture_manifest.json` digest و محدودیت‌های بسته را ثبت می‌کند؛ `environment.json` محیط و مرز اجرای محلی را ثبت می‌کند؛ `results.json` خروجی مرجع آزموده‌شده است. فایل اجرایی همین پوشه در پیوست فصل عیناً درج می‌شود.
