# پروژهٔ فصل ۴۳: ممیزی پیکره پیش از انتشار

این پروژهٔ مستقل به فصل ۴۰ وابستگی اجرایی ندارد و کارهای آن را تکرار نمی‌کند: فصل ۴۰ ساخت یک پیکرهٔ کوچک، split گروهی و vocabulary از train را می‌آموزد؛ این پروژه برای corpus چندمنبعی یک **دفتر ممیزی** می‌سازد که وضعیت ادعاشدهٔ حقوق، پرچم‌های کیفیت، نامزدهای تکرار نزدیک و هم‌پوشانی با مجموعهٔ ارزیابی را کنار هم ثبت می‌کند. هیچ سطری خودکار حذف/ادغام یا برای آموزش صادر نمی‌شود.

## اجرا

- Python 3.11 یا جدیدتر؛ فقط کتابخانهٔ استاندارد؛ CPU کافی است.
- هیچ درخواست شبکه، وب‌گردی، tokenizer، PyTorch، checkpoint یا GPU انجام نمی‌شود.
- از این پوشه اجرا کنید:

```bash
python -m unittest discover -v
python corpus_audit.py
```

برای مسیرهای دیگر:

```bash
python corpus_audit.py \
  --manifest sample_corpus.jsonl \
  --evaluation sample_evaluation.jsonl \
  --output build \
  --target-use pretraining \
  --min-characters 64 \
  --near-threshold 0.70 \
  --evaluation-threshold 0.65 \
  --min-contiguous-tokens 8
```

پروژه ۱۲ رکورد و ۳ مورد ارزیابی **ساختگی و خودنوشته برای آزمون کد** دارد؛ این‌ها corpus واقعی یا benchmark پنهان نیستند. `LicenseRef-CH43-Demo` شناسهٔ قراردادی همین fixture است، نه مجوز استاندارد یا اجازهٔ آموزش. بنابراین رکوردهای `demo-only` مجوز استفادهٔ واقعی نمی‌گیرند.

## خروجی‌ها

- `build/audit.json` — شناسه، hash، شمارش و پرچم هر ردیف؛ بدون متن خام یا URL منبع.
- `build/summary.json` — آمار کل، وضعیت‌های ثبت‌شده و آستانه‌های اجرا.
- `build/data_card.md` — کارت ممیزی نمونه با هدف، ورودی‌ها، روش و محدودیت‌ها.

Hash شناسه‌زدا نیست؛ متن‌های قابل حدس یا کوتاه ممکن است از روی hash قابل تطبیق باشند. برای دادهٔ حساس، انتشار همین گزارش را هم جداگانه ارزیابی کنید.

## قرارداد manifest و مرز حقوق

هر ردیف `id`, `source_id`, `source_uri`, `source_version`, `captured_at`, `license_expression`, `license_url`, `rights_review_status`, `rights_evidence_ref`, `intended_use`, `language` و `text` دارد. وضعیت‌های نمونه `demo-only`, `pending`, `reviewed`, `excluded`اند. برنامه فقط کامل‌بودن فیلدها و status اعلام‌شده را ثبت می‌کند؛ عبارت SPDX را parse نمی‌کند، سند مجوز را دریافت یا تفسیر نمی‌کند، ادعای بازبینی انسانی را راستی‌آزمایی نمی‌کند و هرگز «اجازهٔ آموزش» صادر نمی‌کند. در corpus واقعی، زنجیرهٔ مجوز و شروط upstream، دامنهٔ استفاده، حریم خصوصی، attributed works و حقوق دیگر باید جداگانه و انسانی بررسی شوند.

فیلد خالی، `NOASSERTION`, `pending` یا کاربرد نامنطبق پرچم می‌گیرد؛ نبودن پرچم هم اثبات قانونی‌بودن یا کفایت مجوز نیست. تصمیم کنارگذاری با سابقه و دلیل باید در کنار داده بماند، نه اینکه پاک‌کردن یک فایل، منشأ و تاریخچه را محو کند.

## روش‌های نمونه و محدودیت

- برای تطبیق دقیق، متن به Unicode NFC و whitespace واحد تبدیل می‌شود؛ کلید تطبیق `casefold` می‌شود، ولی punctuation و شکل‌های «ی/ي» و «ک/ك» عمداً یکی نمی‌شوند.
- پرچم‌های ساده شامل متن کوتاه‌تر از آستانه، نویسهٔ جایگزین، نسبت بالای control character و سطرهای تکراری‌اند. هیچ‌کدام به‌تنهایی «کیفیت بد» را ثابت نمی‌کند و هیچ فیلتری حذف خودکار انجام نمی‌دهد.
- تکرار نزدیک با Jaccard روی مجموعهٔ ۳-واژه‌ای (shingle) پیدا می‌شود. جست‌وجو زوج‌به‌زوج است، برای fixture کوچک مناسب است و هزینهٔ آن با تعداد سندها درجه‌دوم رشد می‌کند. در corpus بزرگ‌تر ابزارهای MinHash/LSH یا روش‌های دیگر باید با نمونه‌های مثبت و منفیِ انسانی کالیبره شوند.
- آزمون ارزیابی، تطبیق دقیق، اشتراک حداقل ۸ واژهٔ پیوسته، و نامزد شباهت n-gram را گزارش می‌کند. match **اثبات نمی‌کند** مدل داده را دیده یا نمره‌اش متأثر شده؛ نبود match هم پاک‌بودن را ثابت نمی‌کند. پارافریز، ترجمه، منبع نامعلوم، مدل/دادهٔ آموزشی پنهان و نشت غیرمستقیم پوشش داده نمی‌شوند.
- `sample_evaluation.jsonl` در همین مخزن عمومی است؛ آن را benchmark محرمانه فرض نکنید. در مطالعهٔ واقعی، مجموعهٔ نگه‌داشته‌شده را از pipeline و تصمیم‌های انتخاب فیلتر جدا نگه دارید.
- شمار واژه از regex سادهٔ Unicode می‌آید، نه tokenizer فارسی. زبان و source از manifest خوانده می‌شوند؛ برنامه تشخیص زبان، سنجش نمایندگی، PII scanning جامع، قضاوت کیفیت معنایی یا مشاورهٔ حقوقی انجام نمی‌دهد.

## نتیجهٔ بازتولید نمونه

با تنظیمات پیش‌فرض، اجرای CLI موفق است: ۱۲ رکورد، ۳ مورد ارزیابی، یک جفت تکرار دقیق، یک نامزد تکرار نزدیک، دو نامزد هم‌پوشانی با ارزیابی، ۳ رکورد دارای پرچم کیفیت، ۱۱ رکورد نیازمند بررسی حقوق انسانی/رفع ابهام و یک مورد صریحاً کنارگذاشته‌شده. صفر ردیف برای آموزش صادر می‌شود. این اعداد فقط ویژگی fixture و آستانه‌های همین نسخه‌اند.
