# مقایسه پرسپترون AND و XOR

**هدف:** مقایسه پرسپترون AND و XOR با داده ساختگی.

**پیش‌نیاز:** Python 3.13 و کتابخانه استاندارد. نصب بسته اضافی الزامی نیست.

از همین پوشه: `python perceptron.py`.

**خروجی ثبت‌شده در محیط آزمایش:**

```text
AND weights=[2, 1] bias=-3 outputs=[0, 0, 0, 1] errors=0
XOR weights=[-1, 0] bias=0 outputs=[1, 1, 0, 0] errors=2
```

**آزمون:** `python -m unittest discover -v` از همین پوشه.

**محدودیت:** پرسپترون خطی تک‌لایه XOR را کامل حل نمی‌کند.
