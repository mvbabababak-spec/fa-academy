# پروژهٔ فصل ۳۴: توجه ضرب‌داخلیِ مقیاس‌شده

این پروژه گام‌های اصلی را جداگانه اجرا می‌کند: محاسبهٔ `QKᵀ`، تقسیم بر `√dₖ`، نرمال‌سازی softmax روی محور کلیدها و ضرب در `V`. پیاده‌سازی آموزشی فقط یک سر و تانسورهای سه‌بعدی `[batch, sequence, feature]` را پشتیبانی می‌کند؛ در این فصل ماسک و dropout عمداً اضافه نشده‌اند.

## نیازمندی و اجرا

- Python 3.11 یا جدیدتر
- PyTorch 2.6.x (CPU کافی است؛ نصب CUDA لازم نیست)

از همین پوشه اجرا کنید:

```bash
python attention.py
python -m unittest -v
```

خروجی نمونه باید شامل وزن‌های نزدیک به `[0.66976, 0.33024]`، بردار خروجی نزدیک به `[6.69762, 3.30238]` و `torch_reference_matches=True` باشد. هشت آزمون، ابعاد، محاسبهٔ دستی، نرمال‌شدن وزن‌ها، سازگاری با تابع رسمی PyTorch، گرادیان‌ها و ورودی‌های نامعتبر را می‌سنجند. مقدارهای ممیزشناور می‌توانند با نسخه و سخت‌افزار تفاوت ناچیز داشته باشند.

`attention.py` پیاده‌سازی آشکار و آموزشی را در برابر `torch.nn.functional.scaled_dot_product_attention` با `dropout_p=0.0` و `is_causal=False` مقایسه می‌کند. تابع رسمی ممکن است برحسب سخت‌افزار و ورودی، kernel متفاوتی انتخاب کند؛ در نتیجه برابری باید با تلورانس عددی سنجیده شود، نه با تطبیق بیت‌به‌بیت.
