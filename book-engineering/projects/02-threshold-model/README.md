# آستانه روی داده مصنوعی

**هدف:** آستانه روی داده مصنوعی با داده ساختگی.

**پیش‌نیاز:** Python 3.13 و کتابخانه استاندارد. نصب بسته اضافی الزامی نیست.

از همین پوشه: `python threshold_model.py`.

**خروجی ثبت‌شده در محیط آزمایش:**

```text
threshold=3
test_errors=0/4
test_accuracy=100%
prediction_for_3.5=1
```

**آزمون:** `python -m unittest discover -v` از همین پوشه.

**محدودیت:** ورودی‌ها برای آموزش‌اند؛ fit روی داده خالی به‌جای رد ورودی ۰ می‌دهد.
