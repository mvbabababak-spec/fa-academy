# شبیه‌سازی میانگین گرادیان

**هدف:** شبیه‌سازی میانگین گرادیان با داده ساختگی.

**پیش‌نیاز:** Python 3.13 و کتابخانه استاندارد. نصب بسته اضافی الزامی نیست.

از همین پوشه: `python simulate.py`.

**خروجی ثبت‌شده در محیط آزمایش:**

```text
mean_gradient=0.30
updated_weight=0.97
energy_kwh=3.00
checks=PASS
```

**آزمون:** `python -m unittest discover -v` از همین پوشه.

**محدودیت:** ترتیبی و CPU است؛ چند GPU واقعی نیست.
