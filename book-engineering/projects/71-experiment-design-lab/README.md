# آزمایشگاه فصل ۷۱: طراحی مطالعه و تحلیل جفت‌شده

این آزمایشگاه یک مسیر تحلیلی کوچک را روی اعداد کاملاً ساختگی نشان می‌دهد. هیچ مدل، benchmark، مجموعه‌داده یا پاسخ کاربر اجرا یا ارزیابی نمی‌شود. مثال برای نشان‌دادن تفاوت «ردیف مشاهده» و «واحد مستقل گروه» است؛ فاصلهٔ بازنمونه‌گیری طبقه‌بندی‌شده هم فقط درون بلوک‌های topic و بر گروه‌های ساختگی اعمال می‌شود.

## نیازمندی و اجرا

- CPython 3.13؛ فقط کتابخانهٔ استاندارد.
- بدون شبکه، API، مدل، GPU، دادهٔ شخصی، credential یا وابستگی نصب‌شدنی.
- از این پوشه اجرا کنید:

```sh
python3.13 -m unittest -v test_experiment_design.py
python3.13 experiment_design.py --plan analysis_plan.json --fixture synthetic_paired_scores.json --manifest fixture_manifest.json --output /tmp/ch71-results.json
cmp results.json /tmp/ch71-results.json
```

فرمان دوم manifest را با بایت‌های fixture و طرح تحلیل تطبیق می‌دهد؛ نتیجهٔ قطعی JSON را در مسیر خواسته‌شده می‌نویسد. تطبیق `cmp` فقط پایداری همین برنامه و همین ورودی‌ها را می‌سنجد.

## قرارداد طرح و تفسیر

- `analysis_plan.json` واحد تحلیل، واحد بازنمونه‌گیری، پیامد اصلی، اندازهٔ مثال، روش بازنمونه‌گیری و توقف ثابت را پیش از فایل نتیجه ثبت می‌کند.
- وضعیت طرح `illustrative_only_not_a_preregistration` است: فایل محلی زمان‌مهر، ثبت عمومی پیش از گردآوری یا تضمین عدم تغییر ندارد.
- ۳۲ ردیف در ۸ گروه، ۱۶ task و دو تکرار تو‌در‌توی هر task قرار دارند. گروه، نه ردیف یا تکرار، واحد محاسبهٔ فاصلهٔ bootstrap است؛ گروه‌ها درون سه بلوک topic بازنمونه‌گیری می‌شوند تا شمار هر بلوک ثابت بماند.
- خروجی فقط میانگین اختلاف جفت‌شدهٔ candidate منهای baseline و یک بازهٔ صدکیِ bootstrap طبقه‌بندی‌شده روی هشت گروه مصنوعی را نمایش می‌دهد؛ برای همین fixture، میانگین `0.0421875` و بازه `[0.031875, 0.052187]` است. p-value عمداً محاسبه نمی‌شود و `inference_authorized` همیشه `false` است.
- این فاصله، دقت روش در fixture، برتری مدل، توان آماری، تفاوت واقعی، کیفیت ارزیابی یا قابلیت تعمیم را نشان نمی‌دهد. هشت گروه برای نمونهٔ آموزشی‌اند، نه برای نتیجه‌گیری جمعیتی.

`fixture_manifest.json` digestهای fixture و طرح را نگه می‌دارد؛ `environment.json` محیط واقعی این اجرا را ثبت می‌کند؛ `results.json` خروجی مرجع است. پیوست اجرایی فصل عیناً از `experiment_design.py` گرفته می‌شود.
