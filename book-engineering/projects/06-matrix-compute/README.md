# ضرب ماتریس با CPU

**هدف:** ضرب ماتریس با CPU با داده ساختگی.

**پیش‌نیاز:** Python 3.13 و کتابخانه استاندارد. نصب بسته اضافی الزامی نیست.

از همین پوشه: `python matrix_cpu.py`.

**خروجی ثبت‌شده در محیط آزمایش:**

```text
A x B = [[19, 22], [43, 50]]
correctness=PASS
fp32_payload_2x2_matrices_bytes= 48
```

**آزمون:** `python -m unittest discover -v` از همین پوشه.

**محدودیت:** بنچمارک یا اجرای GPU نیست.
