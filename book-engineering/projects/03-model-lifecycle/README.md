# چرخه آموزش و اعتبارسنجی روی داده مصنوعی

**هدف:** چرخه آموزش و اعتبارسنجی روی داده مصنوعی با داده ساختگی.

**پیش‌نیاز:** Python 3.13 و کتابخانه استاندارد. نصب بسته اضافی الزامی نیست.

از همین پوشه: `python lifecycle.py`.

**خروجی ثبت‌شده در محیط آزمایش:**

```text
lr=0.01 val_mse=0.00000526
lr=0.10 val_mse=0.00000000
selected_lr=0.10
weight=2.000000 bias=1.000000
test_mse=0.00000000
inference_x_7=15.000000
```

**آزمون:** `python -m unittest discover -v` از همین پوشه.

**محدودیت:** داده ناواقعی است؛ mse ورودی خالی را با ZeroDivisionError رد می‌کند.
