# پروژهٔ فصل ۳۵: Self-Attention چندسری با ماسک علّی

این ماژول آموزشی یک توالی `X` را به‌عنوان Query، Key و Value خودش می‌گیرد؛ سه فرافکنی آموختنی می‌سازد، آن‌ها را میان سرها تقسیم می‌کند، برای هر سر ماسک علّی پایین‌مثلثی اعمال می‌کند، خروجی سرها را الحاق و با `W_O` فرافکنی می‌کند. شکل ورودی و خروجی `[batch, length, d_model]` و شکل وزن‌ها `[batch, heads, query, key]` است.

## اجرا

- Python 3.11 یا جدیدتر
- PyTorch 2.6.x (CPU کافی است؛ نصب CUDA لازم نیست)

از همین پوشه:

```bash
python causal_multihead.py
python -m unittest -v
```

نمونه باید خروجی `[1, 5, 8]`، وزن‌های `[1, 2, 5, 5]` و `max_future_weight=0.0` گزارش کند. ده آزمون، ابعاد و وزن‌های هر سر، صفر بودن توجه به آینده، آزمون مداخله‌ایِ عدم نشت آینده، هم‌ارزی محاسبه با SDPA مرجع، semantics ماسک بولی SDPA، گرادیان و ورودی‌های نامعتبر را می‌سنجد.

این کد برای آموزش عمداً positional encoding، padding mask و dropout ندارد و یک Decoder یا مدل زبانی کامل نیست. نتایج CPU کیفیت مدل یا سرعت GPU را ارزیابی نمی‌کنند.
