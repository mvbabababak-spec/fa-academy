# آزمایشگاه رفتار مدل فصل ۶۳

این پروژه یک ممیزی آموزشی و قطعی از fixture ساختگی اجرا می‌کند. خروجی چهار سطح را از هم جدا نگه می‌دارد: برچسب شواهد ادعاها (`supported`، `contradicted` و `unverified`)، سنجه‌های توصیفی طبقه‌بندی و برش‌های گروهی، ثبات پیش‌بینی روی جفت‌های تغییریافتهٔ ساختگی، و آزمون جمع‌پذیری یک تابع خطیِ شناخته‌شده.

## اجرا

```bash
python -m unittest -v
python model_behavior_lab.py --output results.json
```

فقط کتابخانهٔ استاندارد Python لازم است. هیچ مدل، سرویس، وزن، شبکه، منبع بیرونی یا دادهٔ انسانی فراخوانی نمی‌شود. `synthetic_behavior_fixture.json` دادهٔ ساختگی است؛ `fixture_manifest.json` منشأ و SHA-256 آن را ثبت می‌کند. خروجی مرجع در `results.json` قرار دارد.

## خواندن نتیجه

- نسبت پشتیبانی فقط روی ادعاهای resolved (پشتیبانی‌شده یا متناقض با شواهد fixture) حساب می‌شود؛ `unverified` از مخرج کنار می‌ماند. این نسبت «نرخ توهم» یا داوری حقیقت جهان نیست.
- دقت، TPR، FPR، Brier و ECE روی ۱۲ ردیف ساختگی محاسبه می‌شوند. هر cohort فقط ۶ ردیف دارد؛ فاصلهٔ گروهی توصیفی است و نه آزمون تبعیض یا نتیجه‌ای دربارهٔ انسان‌ها.
- ثبات پیش‌بینی روی ۶ جفت «حفظ‌معنا» که در خود fixture چنین برچسب خورده‌اند محاسبه می‌شود. این برچسب‌ها داوری انسانی یا آزمون واقعی معنا نیستند.
- جمع‌پذیری و حذف ویژگی فقط برای تابع خطیِ ازپیش‌دانسته‌شده بررسی می‌شود؛ از آن نمی‌توان دربارهٔ وفاداری توضیح‌های پسینی یک مدل جعبه‌سیاه نتیجه گرفت.

## محدودیت‌ها

این fixture هیچ مدل زبانی یا سامانهٔ مولدی را اجرا نمی‌کند و حقیقت factual claims را مستقل تأیید نمی‌کند. حجم نمونه برای استنباط آماری، برآورد معنادار شکاف، تعمیم یا تصمیم محصولی کافی نیست. ECE به binning و اندازهٔ نمونه وابسته است. معیارهای عدالت انتخاب هنجاری و وابسته به تصمیم و زمینه‌اند. ثبات روی تغییرهای مصنوعی معادل استحکام در برابر جابه‌جایی توزیع یا حمله نیست؛ آزمون خصمانه و امنیتی به فصل ۶۴ واگذار شده است. پاسخ‌های انسانی، کاربردپذیری توضیح، رابطهٔ علّی، حریم خصوصی یا ایمنی محصول در این پروژه آزموده نمی‌شوند.
