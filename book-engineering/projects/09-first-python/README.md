# اولین برنامه پایتون

**هدف:** اولین برنامه پایتون با داده ساختگی.

**پیش‌نیاز:** Python 3.13 و کتابخانه استاندارد. نصب بسته اضافی الزامی نیست.

از همین پوشه: `python hello.py`.

**خروجی ثبت‌شده در محیط آزمایش:**

```text
Hello, AI engineer!
2 + 3 = 5
```

**آزمون:** `python -m unittest discover -v` از همین پوشه.

**محدودیت:** برنامه ورودی ندارد؛ رشته نامعتبر خوانده یا اعتبارسنجی نمی‌شود.
