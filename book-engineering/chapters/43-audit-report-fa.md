# گزارش ممیزی فصل ۴۳ — ممیزی پیکره، مجوز و کیفیت

## دامنه و بازتولید

فصل ۴۳ محلی (فصل ۱۱ جلد سوم) افزوده شده؛ فصل‌های منتشرشدهٔ ۱–۱۰ حفظ شده‌اند. فصل روی provenance و شواهد حقوق، تصمیم فیلتر قابل‌اندازه‌گیری، near-duplicate، هم‌پوشانی ارزیابی، نسخه‌بندی و مستندسازی تمرکز دارد و تکرار پروژهٔ آماده‌سازی و split فصل ۴۰ نیست.

تأیید محیط: `python --version` و `.venv/bin/python --version` هر دو `Python 3.13.16` گزارش کردند؛ پروژهٔ فصل ۴۳ فقط به کتابخانهٔ استاندارد وابسته است.

در `book-engineering/projects/43-corpus-audit/` اجرا شد:

```text
python -m py_compile corpus_audit.py test_corpus_audit.py — موفق
python -m unittest discover -v — ۱۲ از ۱۲ موفق
python corpus_audit.py --output /tmp/ch43-audit-final — موفق
```

## خروجی fixture نمونه

ورودی‌ها ساختگی و خودنوشته‌اند، نه corpus واقعی و نه benchmark محرمانه. خروجی قابل‌بازتولید:

| شمارنده | مقدار |
|---|---:|
| سندهای پیکره / موارد ارزیابی | ۱۲ / ۳ |
| جفت exact duplicate | ۱ |
| نامزد near-duplicate برای بازبینی | ۱ |
| نامزد هم‌پوشانی ارزیابی | ۲ |
| رکورد دارای پرچم کیفیت | ۳ |
| مورد نیازمند بازبینی حقوق/رفع ابهام انسانی | ۱۱ |
| مورد صریحاً کنارگذاشته‌شده | ۱ |
| ردیف صادرشده برای آموزش | ۰ |

ابزار متن خام را در گزارش نمی‌نویسد و نه داده‌ای را حذف/دانلود/تأیید می‌کند و نه اجازهٔ آموزش صادر می‌کند. نامزد هم‌پوشانی سند، به‌تنهایی اثبات مواجههٔ یک مدل یا اثر بر نمره نیست؛ نبود match نیز نبود آلودگی را اثبات نمی‌کند. برچسب‌های مجوز fixture اجازهٔ استفادهٔ واقعی نیستند.

## بررسی ساخت و یکپارچگی محلی

- سه checker ساختار جلدها موفق شدند: جلد اول ۲۱ فصل و ۲۳۶ بخش؛ جلد دوم ۱۱ فصل و ۱۰۱ بخش؛ جلد سوم ۱۱ از ۱۴ فصل و ۱۹۰ بخش. checker جلد سوم ۱۱ تصویر محلی، ۱۱ پاسخ‌نامه و ۴۷ بلوک MathML دسترس‌پذیر را تأیید کرد.
- آزمون‌های واحد پروژه‌های جلد سوم، فصل‌های ۳۳–۴۳، همگی موفق شدند: **۱۶۰/۱۶۰**. CLI بودجهٔ فصل ۴۲ و CLI ممیزی فصل ۴۳ هم اجرا شدند.
- builder جلد سوم دوباره اجرا شد؛ `data.json` و `volume-3-full-fa.md` با خروجی قبلی byte-for-byte برابر ماندند.
- آزمون مرورگر جلد سوم در ۳۲۰، ۳۹۰ و ۱۴۴۰ پیکسل موفق شد: ۱۹۰ بخش، ۴۷ MathML، ۱۱ تصویر، جست‌وجو/ناوبری و ۸۸ فایل cache آفلاین در Service Worker v69.
- آزمون مرورگر جلد دوم در ۳۲۰، ۳۹۰ و ۱۴۴۰ پیکسل موفق شد؛ آزمون layout کل کتاب در ۳۲۰، ۳۹۰، ۴۱۴، ۷۶۸ و ۱۴۴۰ پیکسل، ۷۳۰ بخش را بدون شکست layout گزارش کرد.

## محدودیت‌های آزمون

لاگ مرورگر چند 404 قدیمی در تصویرهای جلدهای پیشین نشان داد؛ مسیرهای مربوط به فصل ۴۳ (متن، پاسخ، پروژه و تصویر) در آزمون offline حاضر بودند و آزمون شکست نخورد. اجرای CLI قدیمی فصل ۴۲ نیز هشدار اختیاری PyTorch دربارهٔ نصب‌نبودن NumPy داد؛ فرمان با موفقیت تمام شد. ابزار فصل ۴۳ شبکه، مدل، PII detector جامع یا سیستم حقوقی را اجرا نمی‌کند. گزارش checker و آزمون‌ها تأیید حقوق، کیفیت زبان یا نبود آلودگی مدل نیستند.

این گزارش نتایج محلی همین snapshot را ثبت می‌کند؛ وضعیت GitHub Actions/Pages باید جداگانه پس از push بررسی شود.
