# گزارش ممیزی فصل ۳۴ — نسخهٔ محلی

**تاریخ اجرا:** ۵ نوامبر ۲۰۲۶ · **دامنه:** فصل ۲ جلد سوم (فصل سراسری ۳۴)، پروژه، پاسخ‌نامه، تصویر و مسیرهای نمایش/آفلاین.

## محیط ثبت‌شده

- Python 3.13.16 روی Linux؛ اجرای پروژه روی CPU.
- PyTorch `2.6.0+cpu`؛ آزمون CUDA/GPU اجرا نشد.
- Pillow 13.0.0، Mistune 3.4.0، Playwright 1.64.1 و Chromium for Testing 156.0.8078.4.

## نتیجهٔ آزمون‌های پروژه

- `cd book-engineering/projects/34-attention && python -m unittest discover -v` — **۸ آزمون موفق**: محاسبهٔ دستی، ابعاد دسته‌ای و طول‌های متفاوت پرس‌وجو/منبع، نرمال‌بودن ردیف وزن‌ها، انطباق خروجی با API مرجع در tolerance، گرادیان متناهی، softmax برای امتیاز بزرگ متناهی و ورودی‌های نامعتبر.
- `python attention.py` — CPU؛ امتیاز مقیاس‌شده `[[[0.7071067812, 0.0]]]`؛ وزن‌ها `[[[0.6697615493, 0.3302384507]]]`؛ خروجی `[[[6.6976154933, 3.3023845067]]]`؛ `torch_reference_matches=True`.
- آزمون بازبینی پروژهٔ فصل ۳۳ در همین محیط: `python -m unittest discover -v` در `projects/33-tokenization/` — **۱۴ آزمون موفق**؛ محتوای فصل ۳۳ در این کار بازنویسی نشده است.
- شکل منبع تصویر `v3-ch02-attention.webp`: **1600×1000 پیکسل**، WebP، 69,226 بایت؛ نمودار با Pillow و منبع Python پروژه ساخته شد، نه با متن تصویریِ مولد.

## ساختار، مرورگر و آفلاین

- `python book-engineering/check_volume3.py` — **موفق**: ۲/۱۴ فصل، ۲۴ بخش، دو WebP محلی با alt معنادار، دو جواب‌نامه و هفت بلوک MathML دارای `aria-label`؛ همچنین همگامی کد فصل‌های ۳۳ و ۳۴ با پروژه‌ها بررسی شد.
- اجرای دوم `python book-engineering/build_volume3.py` — **idempotent**: `2/14` و `[11, 13]` بخش را گزارش کرد؛ hash فایل‌های `data.json` و `volume-3-full-fa.md` پیش و پس از اجرا یکسان ماند.
- `python book-engineering/test_volume3.py` — **موفق در ۳۲۰، ۳۹۰ و ۱۴۴۰ پیکسل**: بارگذاری ۲۴ بخش، نمایش MathML، دو تصویر ۱۶۰۰×۱۰۰۰، جست‌وجو، hash پایدار، رفت‌وبرگشت ناوبری بین فصل‌ها، Service Worker v60 و دریافت آفلاین ۱۶ فایل آزموده شد.
- `python book-engineering/check_volume.py` و `check_volume2.py` — موفق؛ به‌ترتیب ۲۱ فصل/۲۳۶ بخش و ۱۱ فصل/۱۰۱ بخش با کنترل‌های ساختاری.
- `python book-engineering/test_volume2.py` — موفق در عرض‌های ۳۲۰، ۳۹۰ و ۱۴۴۰ پیکسل؛ ناوبری، hash، جست‌وجو و ۲۲ فایل آفلاین.
- `python book-engineering/test_mobile_layout.py` — موفق در عرض‌های ۳۲۰، ۳۹۰، ۴۱۴، ۷۶۸ و ۱۴۴۰ پیکسل؛ پوشش ۵۶۴ بخش.

در لاگ مرورگر چند درخواست 404 برای تصویرهای قدیمیِ موجود در دادهٔ کتاب/دورهٔ دیگری دیده شد؛ نمونهٔ تصویر بندانگشتی هوش مولد هم در snapshot راه‌دورِ پیش از این تغییر غایب بود. این موارد به فایل‌های جدید فصل ۳۴ مربوط نیستند، اصلاح نشدند و در آزمون‌های chapter/offline مانع کار نبودند. `pageerror` تازه‌ای ثبت نشد. آزمون مرورگر به‌تنهایی پوشش Safari/iOS یا دستگاه فیزیکی نیست.

## محدودیت و وضعیت انتشار

این پروژه یک نمونهٔ تک‌سر و بدون mask/dropout است؛ آزمون CPU، صحت مدل زبانی کامل، تفسیرپذیری وزن‌ها، کارایی GPU یا برتری یک kernel را اثبات نمی‌کند. اختلاف عددی کوچک میان backendها ممکن است. PDF و EPUB تولید نشده‌اند. نتیجهٔ GitHub Actions و اجرای نسخهٔ زندهٔ Pages تا مشاهدهٔ واقعی گزارش نمی‌شود.
