# پاسخ‌نامه فصل ۶ — GPU و موازی‌سازی

**هنر و علم ساخت هوش | Babak & Ai**

## پاسخ مفهومی

۱. CPU عمومی‌تر است و GPU برای بارهای موازی مناسب است. ۲. خیر، GPU همیشه سریع‌تر نیست. ۳. NPU ممکن است فقط بخشی از عملگرها را پشتیبانی کند. ۴. ظرفیت حجم قابل نگهداری و پهنای باند نرخ انتقال است. ۵. فعال‌سازی، بافر و گرادیان نیز حافظه می‌خواهند. ۶. خیر، shared memory در CUDA با حافظه یکپارچه سیستم یکسان نیست. ۷. سربار و شکل واقعی کار بر سرعت مؤثرند. ۸. خیر، `empty_cache` حافظه tensor زنده را آزاد نمی‌کند. ۹. حجم داده و پهنای باند واقعی بر زمان انتقال اثر دارند. ۱۰. نمونه کوچک CPU عملکرد GPU را اندازه نمی‌گیرد.

## تمرین ریاضی

۱. `1/(0.5+0.5/2) = 4/3 ≈ 1.33` برابر، تحت فرض‌های ساده مدل. ۲. دو میلیارد بایت خام، بدون سربار. ۳. ابعاد خروجی `3×4` است.
