- پروژه‌های فصل‌های ۶ و ۷ با Python 3.13.16 در محیط بدون PyTorch/GPU آزمایش شده‌اند؛ شاخه‌های دستگاهی و نمونه PyTorch روی سخت‌افزار واقعی آزمایش نشده‌اند.
