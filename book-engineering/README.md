- پروژه‌های فصل‌های ۸ تا ۱۰ با Python 3.13.16 اجرا شده‌اند. پروژه فصل ۸ شبیه‌سازی CPU است و یک اجرای چند GPU واقعی نیست.

## ساخت و انتشار جلد دوم

جلد دوم شامل فصل‌های محلی ۱–۱۱ (سراسری ۲۲–۳۲) است. انتشار وب/PWA است؛ PDF و EPUB تولید و آزموده نشده‌اند. فایل قابل دریافت `../volume-2-full-fa.md` است. از ریشه مخزن و پس از نصب Mistune 3.4.0 به ترتیب `python book-engineering/build_volume2.py`، `python book-engineering/append_volume2_04_06.py`، `python book-engineering/append_volume2_07_09.py`، `python book-engineering/append_volume2_10_11.py` را اجرا کنید. این سازنده‌ها فصل موجود ناسازگار را بازنویسی نمی‌کنند؛ برای اصلاح محتوای منتشرشده ابتدا منبع و داده همگام، نسخه SW افزایش و تست‌ها اجرا شوند. `python book-engineering/check_volume2.py` و `python book-engineering/test_volume2.py` کنترل ساختار و مرورگر را انجام می‌دهند؛ دومی Playwright و Chromium می‌خواهد. برای حفظ تاریخچه، توضیحات پیشین این فایل به زمان نگارش خود مربوط‌اند.

**رده‌بندی پروژه‌ها:** ۱۱ پروژه فصل‌های جلد دوم تمرین‌های مستقل اجرایی آن فصل‌ها هستند؛ پروژه تلفیقی پایان بخش، فعالیت ارزیابی جامع است و الزاماً پروژه جدید یا پوشه مستقل نیست؛ ۲۰ پروژه اصلی جدول نقشه مسیرهای سراسری مجموعه‌اند و برخی با پروژه‌های فصلی هم‌پوشانی دارند. این دسته‌ها را نباید با هم جمع زد یا هم‌ارز شمرد.

## ساخت و انتشار تدریجی جلد سوم

طبق نقشهٔ کامل پنج‌جلدی، جلد سوم ۱۴ فصل محلی دارد که برابر فصل‌های سراسری ۳۳–۴۶ است. در این انتشار ۵ نوامبر ۲۰۲۶، فصل‌های محلی ۱ تا ۶ (سراسری ۳۳: توکن‌سازی؛ ۳۴: توجه و Q/K/V؛ ۳۵: Self-Attention، چندسری و ماسک علّی؛ ۳۶: موقعیت، RoPE، اتصال باقیمانده، LayerNorm و FFN؛ ۳۷: Encoder، Decoder و Encoder–Decoder؛ ۳۸: پنجرهٔ متن، KV Cache، GQA، Sparse Attention، MoE و زمینهٔ بلند) نوشته و آزموده شده‌اند؛ ۸ فصل دیگر هنوز منتشر نشده‌اند. منبع/پاسخ‌نامه/پروژه به‌ترتیب در `chapters/33-tokenization.md`، `answers/33-tokenization-fa.md`، `projects/33-tokenization/`؛ `chapters/34-attention.md`، `answers/34-attention-fa.md`، `projects/34-attention/`؛ `chapters/35-self-attention.md`، `answers/35-self-attention-fa.md`، `projects/35-self-attention/`؛ `chapters/36-position-normalization.md`، `answers/36-position-normalization-fa.md`، `projects/36-position-normalization/`؛ `chapters/37-encoder-decoder.md`، `answers/37-encoder-decoder-fa.md`، `projects/37-encoder-decoder/`؛ و `chapters/38-long-context.md`، `answers/38-long-context-fa.md`، `projects/38-long-context/` قرار دارند. `volume-3-full-fa.md` متن قابل دریافت فصل‌های منتشرشده را دارد.

پس از نصب `mistune==3.4.0` از ریشه مخزن `python book-engineering/build_volume3.py` را اجرا کنید. سازنده فقط فصل‌های دارای منبع پیوسته از شماره ۱ را اضافه می‌کند، شناسه‌های پایدار می‌سازد و فصل منتشرشدهٔ ناسازگار را بازنویسی نمی‌کند. اگر آخرین فصلِ موجود فقط پیش‌نویس محلی و هنوز در remote منتشر نشده است، ابتدا tip و نبود فایل فصل را در remote مستقل بررسی کنید؛ سپس `python book-engineering/build_volume3.py --refresh-last-draft` فقط همان فصل پایانی را، مشروط به ثابت‌ماندن ID فصل و همهٔ بخش‌ها، بازسازی می‌کند. این گزینه برای فصل منتشرشده یا تغییری که ID بخش را عوض کند مجاز نیست. پس از اصلاح منبع فصل منتشرشده، همگام‌سازی داده/نسخه و آزمون بازبینی مستقل لازم است.

آزمون پروژه‌های فصل‌های ۳۳ تا ۳۸ را از `projects/33-tokenization/`، `projects/34-attention/`، `projects/35-self-attention/`، `projects/36-position-normalization/`، `projects/37-encoder-decoder/` و `projects/38-long-context/` جداگانه با `python -m unittest discover -v` اجرا کنید. پروژهٔ ۳۳ از کتابخانهٔ استاندارد Python استفاده می‌کند و آزمون lookup آن به PyTorch 2.6.0 CPU نیاز دارد؛ پروژه‌های ۳۴ تا ۳۸ نیز PyTorch 2.6.x CPU می‌خواهند. آزمون فصل ۳۸، maskهای علّی/محلی، GQA/MQA، cache افزایشی، برآورد KV و routing سادهٔ MoE را در ۲۵ آزمون واحد کنترل می‌کند؛ benchmark سرعت یا کیفیت نیست. کنترل ساختار/MathML/تصویر/پاسخ/همگامی کد: `python book-engineering/check_volume3.py`. آزمون Chromium در عرض‌های ۳۲۰، ۳۹۰ و ۱۴۴۰ پیکسل، ناوبری میان‌فصلی، جست‌وجو و فایل‌های آفلاین: `python book-engineering/test_volume3.py`؛ Playwright 1.64.1 و Chromium لازم است. گردش‌کار `.github/workflows/volume3-audit.yml` هر شش پروژه و آزمون مرورگر را اجرا می‌کند؛ وضعیت راه‌دور آن پس از push باید در Actions بررسی شود.

سرویس‌ورکر v64 پیش‌دریافت متن، شش تصویر WebP، پاسخ‌نامه‌ها، گزارش‌های فصل‌های ۳۳ تا ۳۸ و فایل‌های اجرایی/آزمون شش پروژهٔ جلد سوم را انجام می‌دهد. آزمون محلی آفلاین، همهٔ ۴۴ مسیر فهرست‌شده را صریحاً بررسی می‌کند. این آزمون به معنی تأیید تمام دوره‌های قدیمی، Safari/iOS یا دستگاه فیزیکی نیست. انتشار وب/PWA است؛ PDF و EPUB تولید و آزموده نشده‌اند. فصل‌های ۷–۱۴ جلد سوم، GPU واقعی، مرورگرهای دیگر و دستگاه فیزیکی اجرا یا تأیید نشده‌اند.
