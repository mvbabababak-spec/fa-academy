## ساخت و انتشار جلد دوم

جلد دوم شامل فصل‌های محلی ۱–۱۱ (سراسری ۲۲–۳۲) است. انتشار وب/PWA است؛ PDF و EPUB تولید و آزموده نشده‌اند. فایل قابل دریافت `../volume-2-full-fa.md` است. از ریشه مخزن و پس از نصب Mistune 3.4.0 به ترتیب `python book-engineering/build_volume2.py`، `python book-engineering/append_volume2_04_06.py`، `python book-engineering/append_volume2_07_09.py`، `python book-engineering/append_volume2_10_11.py` را اجرا کنید. این سازنده‌ها فصل موجود ناسازگار را بازنویسی نمی‌کنند؛ برای اصلاح محتوای منتشرشده ابتدا منبع و داده همگام، نسخه SW افزایش و تست‌ها اجرا شوند. `python book-engineering/check_volume2.py` و `python book-engineering/test_volume2.py` کنترل ساختار و مرورگر را انجام می‌دهند؛ دومی Playwright و Chromium می‌خواهد. برای حفظ تاریخچه، توضیحات پیشین این فایل به زمان نگارش خود مربوط‌اند.

**رده‌بندی پروژه‌ها:** ۱۱ پروژه فصل‌های جلد دوم تمرین‌های مستقل اجرایی آن فصل‌ها هستند؛ پروژه تلفیقی پایان بخش، فعالیت ارزیابی جامع است و الزاماً پروژه جدید یا پوشه مستقل نیست؛ ۲۰ پروژه اصلی جدول نقشه مسیرهای سراسری مجموعه‌اند و برخی با پروژه‌های فصلی هم‌پوشانی دارند. این دسته‌ها را نباید با هم جمع زد یا هم‌ارز شمرد.

## ساخت و انتشار تدریجی جلد سوم

طبق نقشهٔ کامل پنج‌جلدی، جلد سوم ۱۴ فصل محلی دارد که با فصل‌های سراسری ۳۳–۴۶ متناظرند. تا این انتشار فصل‌های محلی ۱–۹ (سراسری ۳۳–۴۱) تکمیل شده‌اند: توکن‌سازی؛ Attention و Q/K/V؛ Self-Attention؛ positional encoding و اجزای Transformer؛ خانواده‌های Encoder/Decoder؛ زمینهٔ بلند؛ Transformer چندوجهی؛ پیکرهٔ کوچک و آماده‌سازی داده؛ و نخستین مدل زبانی کوچک با آموزش، ارزیابی و تولید. گام بعدی محلی ۱۰ / سراسری ۴۲، Mini GPT است. فصل‌های منتشرشده را بازنویسی نکنید.

منبع هر فصل در `chapters/`، پاسخ‌نامه در `answers/`، و پروژهٔ مستقل در `projects/` قرار دارد. فصل تازهٔ این انتشار: `chapters/41-first-language-model.md`، `answers/41-first-language-model-fa.md` و `projects/41-first-language-model/`. شکل فنی از SVG منبع در `diagrams/v3-ch09-training-loop.svg` و اسکریپت `create_v3_ch09_image.py` به WebP محلی تبدیل می‌شود؛ به قلم یا تصویر remote وابسته نیست. `volume-3-full-fa.md` نسخهٔ Markdown فصل‌های منتشرشده را جمع می‌کند.

### ساخت، آزمون و ممیزی

از ریشهٔ مخزن و با Python 3.13.16، پس از نصب `mistune==3.4.0`، اجرا کنید:

```bash
python book-engineering/build_volume3.py
python book-engineering/check_volume3.py
```

سازنده فقط فصل‌های دارای منبع پیوسته از شمارهٔ ۱ را اضافه می‌کند و شناسه‌های پایدار می‌سازد؛ فصل منتشرشدهٔ ناسازگار را بازنویسی نمی‌کند. گزینهٔ `--refresh-last-draft` فقط برای آخرین draft محلیِ هنوز منتشرنشده است و پس از کنترل remote و حفظ همهٔ IDها مجاز است.

پروژه‌های فصل‌های ۳۳ تا ۴۱ را جداگانه با `python -m unittest discover -v` از پوشهٔ همان پروژه اجرا کنید. پروژهٔ فصل ۴۰ Python 3.11+ و کتابخانهٔ استاندارد می‌خواهد. پروژهٔ فصل ۴۱ به Python 3.11+ و PyTorch 2.6.x CPU نیاز دارد؛ برای مقایسهٔ تنظیمات از `--skip-test` استفاده کنید و فقط اجرای نهایی را بدون آن انجام دهید. ۲۲ آزمون آن، قرارداد داده و hash، واژگان و زمینه، ابعاد/زیان/گرادیان، seed، checkpoint، تولید و CLI را می‌سنجند؛ کیفیت زبان، تعمیم، حقوق داده یا ایمنی محصول را اثبات نمی‌کنند. دستور نصب CPU و محدودیت‌ها در `projects/41-first-language-model/README.md` است.

آزمون مرورگر جلد سوم: `python book-engineering/test_volume3.py`؛ آزمون layout کل کتاب: `python book-engineering/test_mobile_layout.py`. هر دو به Playwright 1.64.1، Chromium و Pillow 13.0.0 نیاز دارند. تست جلد سوم ناوبری، شناسه‌های پایدار، search، MathML دسترس‌پذیر، overflow، تصاویر و ۶۸ فایل آفلاین را در عرض‌های ۳۲۰، ۳۹۰ و ۱۴۴۰ پیکسل بررسی می‌کند؛ آزمون موبایل ۳۲۰، ۳۹۰، ۴۱۴، ۷۶۸ و ۱۴۴۰ پیکسل را می‌سنجد. برای آزمون آفلاین، Service Worker روی v67 است. گردش‌کار `.github/workflows/volume3-audit.yml` checkerها، پروژه‌های جلد سوم، idempotence سازنده، آزمون مرورگر جلد دوم/سوم و layout موبایل را اجرا می‌کند.
