## ساخت و انتشار جلد دوم

جلد دوم شامل فصل‌های محلی ۱–۱۱ (سراسری ۲۲–۳۲) است. انتشار وب/PWA است؛ PDF و EPUB تولید و آزموده نشده‌اند. فایل قابل دریافت `../volume-2-full-fa.md` است. از ریشه مخزن و پس از نصب Mistune 3.4.0 به ترتیب `python book-engineering/build_volume2.py`، `python book-engineering/append_volume2_04_06.py`، `python book-engineering/append_volume2_07_09.py`، `python book-engineering/append_volume2_10_11.py` را اجرا کنید. این سازنده‌ها فصل موجود ناسازگار را بازنویسی نمی‌کنند؛ برای اصلاح محتوای منتشرشده ابتدا منبع و داده همگام، نسخه SW افزایش و تست‌ها اجرا شوند. `python book-engineering/check_volume2.py` و `python book-engineering/test_volume2.py` کنترل ساختار و مرورگر را انجام می‌دهند؛ دومی Playwright و Chromium می‌خواهد. برای حفظ تاریخچه، توضیحات پیشین این فایل به زمان نگارش خود مربوط‌اند.

**رده‌بندی پروژه‌ها:** ۱۱ پروژه فصل‌های جلد دوم تمرین‌های مستقل اجرایی آن فصل‌ها هستند؛ پروژه تلفیقی پایان بخش، فعالیت ارزیابی جامع است و الزاماً پروژه جدید یا پوشه مستقل نیست؛ ۲۰ پروژه اصلی جدول نقشه مسیرهای سراسری مجموعه‌اند و برخی با پروژه‌های فصلی هم‌پوشانی دارند. این دسته‌ها را نباید با هم جمع زد یا هم‌ارز شمرد.

## ساخت و انتشار تدریجی جلد سوم

طبق نقشهٔ کامل پنج‌جلدی، جلد سوم ۱۴ فصل محلی دارد که برابر فصل‌های سراسری ۳۳–۴۶ است. در انتشار مرحله‌ای این نوبت، فصل‌های محلی ۱ تا ۸ (سراسری ۳۳ تا ۴۰) تکمیل شده‌اند: ۳۳ توکن‌سازی؛ ۳۴ توجه و Q/K/V؛ ۳۵ Self-Attention، چندسری و ماسک علّی؛ ۳۶ موقعیت، RoPE، اتصال باقیمانده، LayerNorm و FFN؛ ۳۷ Encoder، Decoder و Encoder–Decoder؛ ۳۸ پنجرهٔ متن، KV Cache، GQA، Sparse Attention، MoE و زمینهٔ بلند؛ ۳۹ Transformer چندوجهی؛ و ۴۰ پروژهٔ دادهٔ کوچک، منشأ/مجوز، پاک‌سازی، split گروهی و tokenizer پایه. فصل‌های ۱ تا ۷ پیش‌تر منتشر شده‌اند؛ فصل ۸/۴۰ با commit مستقل این مرحله منتشر می‌شود. فصل‌های محلی ۹–۱۴ هنوز نوشته نشده‌اند. مسیر منبع/پاسخ‌نامه/پروژه برای فصل ۴۰ به‌ترتیب `chapters/40-small-data-project.md`، `answers/40-small-data-project-fa.md` و `projects/40-small-data-project/` است؛ فصل‌های ۳۳–۳۹ نیز در مسیرهای هم‌نام و فهرست‌شده در نسخه‌های پیشین همین پوشه قرار دارند. `volume-3-full-fa.md` متن فصل‌های منتشرشده را دارد.

Commit فصل ۳۹ با شناسهٔ `32e36903ad7bc74b159f5b6802f1b4fd1fb5cea7` در remote تأیید شد؛ آزمون Volume 3 run `42062777294` و Pages build/deployment run `42062776073` برای همان commit موفق‌اند. برای فصل تازه، GitHub Actions پس از push مستقل دوباره بررسی می‌شود.

پس از نصب `mistune==3.4.0` از ریشهٔ مخزن `python book-engineering/build_volume3.py` را اجرا کنید. سازنده فقط فصل‌های دارای منبع پیوسته از شمارهٔ ۱ را اضافه می‌کند، شناسه‌های پایدار می‌سازد و فصل منتشرشدهٔ ناسازگار را بازنویسی نمی‌کند. اگر آخرین فصل موجود فقط پیش‌نویس محلی و هنوز در remote منتشر نشده است، ابتدا tip و نبود فایل فصل را در remote مستقل بررسی کنید؛ سپس `python book-engineering/build_volume3.py --refresh-last-draft` فقط همان فصل پایانی را، مشروط به ثابت‌ماندن ID فصل و همهٔ بخش‌ها، بازسازی می‌کند. این گزینه برای فصل منتشرشده یا تغییری که ID بخش را عوض کند مجاز نیست.

آزمون پروژه‌های فصل‌های ۳۳ تا ۴۰ را از `projects/33-tokenization/`، `projects/34-attention/`، `projects/35-self-attention/`، `projects/36-position-normalization/`، `projects/37-encoder-decoder/`، `projects/38-long-context/`، `projects/39-multimodal-transformer/` و `projects/40-small-data-project/` جداگانه با `python -m unittest discover -v` اجرا کنید. پروژهٔ ۴۰ به Python 3.11+ و کتابخانهٔ استاندارد نیاز دارد؛ ۲۰ آزمون واحد آن manifest و اعتبارسنجی، dedup دقیق، split گروهی، vocabulary train-only، tokenizer و خروجی‌های مستند را می‌سنجند؛ مجوز واقعی یا حذف کامل PII را اثبات نمی‌کنند. پروژه‌های ۳۴–۳۹ PyTorch 2.6.x CPU می‌خواهند و آزمون lookup پروژهٔ ۳۳ نیز PyTorch 2.6.0 CPU لازم دارد. کنترل ساختار/MathML/تصویر/پاسخ/همگامی کد: `python book-engineering/check_volume3.py`. آزمون Chromium در عرض‌های ۳۲۰، ۳۹۰ و ۱۴۴۰ پیکسل، ناوبری میان‌فصلی، جست‌وجو و فایل‌های آفلاین: `python book-engineering/test_volume3.py`؛ Playwright 1.64.1 و Chromium لازم است. گردش‌کار `.github/workflows/volume3-audit.yml` هر هشت پروژه و آزمون مرورگر را اجرا می‌کند.

سرویس‌ورکر v66 پیش‌دریافت متن، هشت تصویر WebP، پاسخ‌نامه‌ها، گزارش‌های فصل‌های ۳۳ تا ۴۰ و فایل‌های پروژه‌های جلد سوم را انجام می‌دهد. آزمون آفلاین ۵۹ مسیر را صریحاً بررسی می‌کند؛ آزمون Playwright نیز ۱۲۹ بخش، ناوبری، جست‌وجو، MathML و نمایش سه‌عرضی را می‌سنجد. این آزمون‌ها به معنی تأیید تمام دوره‌های قدیمی، Safari/iOS، GPU واقعی یا دستگاه فیزیکی نیستند. انتشار وب/PWA است؛ PDF و EPUB تولید و آزموده نشده‌اند. فصل‌های محلی ۹–۱۴ جلد سوم، مرورگرهای دیگر و دستگاه فیزیکی اجرا یا تأیید نشده‌اند.
