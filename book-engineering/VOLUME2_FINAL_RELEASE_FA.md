## آزمون و نتایج

در مبنا جلد دوم ۱۱ پروژه و ۶۷ تست، کل مجموعه ۳۵ پروژه و ۱۴۹ تست داشت. پس از ممیزی ۳۵ مجموعه تست با ۱۵۲ تست موفق شدند؛ از این تعداد ۷۰ تست در ۱۱ پروژه جلد دوم و ۸۲ تست در پروژه‌های جلد اول‌اند. Python 3.13.16، NumPy 2.3.5، scikit-learn 1.6.1، PyTorch 2.6.0+cpu، Mistune 3.4.0، Playwright 1.64.1 و Chromium استفاده شدند. همه پروژه‌ها روی CPU اجرا شدند. خروجی‌های عددی گزارش‌شده در فصل‌ها تغییر نکردند؛ اصلاحات شامل اعتبارسنجی ε، آزمون پایداری سیگموید، قرارداد KNN و حذف وابستگی `globals` در forward بود. تغییر API فصل ۲۷ به `library_forward(X, training_X, training_y)` عمدی و در README آن مستند است. هشدار deprecation SciPy درباره گزینه‌های L-BFGS-B باقی است.

کنترل ساختاری `check_volume2.py`، چهار سازنده و یکسان‌ماندن `data.json` پس از اجرای آنها، و آزمون Chromium در عرض‌های ۳۲۰، ۳۹۰ و ۱۴۴۰ با ناوبری، جست‌وجو، ۱۰۱ بخش و ۲۲ دارایی آفلاین موفق شدند. موفقیت آفلاین این جلدها به معنی تأیید همه دوره‌ها و تمام دارایی‌های اپ نیست؛ برخی منابع قدیمی دوره‌ها پیش‌تر ۴۰۴ بودند. اجرای GitHub Actions در سرور GitHub هنوز باید در رابط Actions تأیید شود.
